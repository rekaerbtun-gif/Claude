# Ops Daily Bot

An internal product for the parking-operations team:

- a **Microsoft Teams bot** that runs the daily rhythm: morning briefing → 1-3-5 plan →
  check-ins → end-of-day close-out, plus live alerts for critical tickets
- a **web app** for tickets, SLA rules, masters (dropdown lists), reports, and the knowledge base

**Status:** scoping. See [`docs/SCOPE.md`](docs/SCOPE.md).
