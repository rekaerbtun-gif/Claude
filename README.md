# Ops Daily System

A daily operating system for the parking-operations team, built on Microsoft 365:

- **Teams** delivers the daily rhythm: 09:00 briefing → 1-3-5 plan → check-ins → 18:00 close-out,
  plus alerts and escalation for critical tickets
- **Microsoft Lists** replaces the Excel ticket sheet and stores plans and close-outs
- **Power Automate** runs the schedule and escalations
